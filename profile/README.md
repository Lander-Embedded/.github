# Embedded

Novel electronics projects and accompanying software.

## [NeGcon PS3 Pad](https://github.com/Lander-Embedded/negcon-ps3-pad)

A Teensyduino-based adapter for playing PS3 and PC games with a NeGcon controller.

## [QMK Firmware ](https://github.com/Lander-Embedded/qmk_firmware)

Modified firmware for the ZSA Moonlander split keyboard.

Features a custom 'quick-switch' modifier, layering, and audio feedback on state change.
